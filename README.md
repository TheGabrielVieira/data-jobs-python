# 📊 Data Jobs Analysis with Python

Projeto de análise de dados focado no mercado de trabalho em tecnologia, com ênfase em vagas da área de dados (Data Science, Data Analyst, Data Engineer).

O objetivo é explorar, limpar e analisar dados para gerar insights relevantes sobre salários, tecnologias mais requisitadas e tendências do mercado.

---

## 🚀 Objetivos

- Analisar dados de vagas na área de dados
- Identificar padrões de salários
- Explorar tecnologias mais demandadas
- Gerar insights para quem deseja ingressar na área
- Praticar análise de dados com Python

---

## 🧠 Tecnologias Utilizadas

- Python 3
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

---

## 🔍 Etapas do Projeto

### 1. Coleta de Dados
- Importação de dataset contendo informações sobre vagas

### 2. Limpeza de Dados
- Tratamento de valores nulos
- Padronização de colunas
- Remoção de inconsistências

### 3. Análise Exploratória (EDA)
- Distribuição de salários
- Frequência de tecnologias
- Comparação por localização

### 4. Visualização de Dados
- Gráficos de barras
- Histogramas
- Heatmaps

---

## 📈 Principais Insights

- 💰 Faixa salarial varia significativamente por experiência
- 🧑‍💻 Python é uma das tecnologias mais requisitadas
- 🌎 Vagas remotas estão em crescimento
- 📊 Ferramentas de BI (Power BI, Tableau) continuam relevantes

## ▶️ Como Executar o Projeto

### 1. Clone o repositório

git clone https://github.com/TheGabrielVieira/data-jobs-python.git
cd data-jobs-python

### 2. Crie um ambiente virtual

python -m venv venv

Ative o ambiente:

Windows:
venv\Scripts\activate

Linux/Mac:
source venv/bin/activate

### 3. Instale as dependências

pip install -r requirements.txt

### 4. Execute o notebook

jupyter notebook
